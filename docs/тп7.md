## Документ ТП-07. Комплекс технических средств (КТС) и инфраструктурное обеспечение

**Шифр документа:** АИС-ЦС-2026-ТП-07  
**Стадия по ГОСТ 34.601-90:** Технический проект  
**Версия:** 1.0 (Утверждённая)  

---

### 1. Назначение и состав комплекса технических средств

Настоящий документ регламентирует состав, технические характеристики, схемы компоновки, требования к электропитанию, заземлению и сетевой инфраструктуре аппаратных средств АИС «Склад-МехПром» на центральном складе АО «МехПром».

Комплекс технических средств (КТС) подразделяется на 5 основных групп:
1. Серверный комплекс (сервер приложений и СУБД, система резервного копирования).
2. Стационарные автоматизированные рабочие места (АРМ администратора, кладовщиков, инженера ОТК).
3. Мобильные терминалы сбора данных (ТСД) комплектовщиков и водителей ричтраков.
4. Периферийное технологическое оборудование (принтеры маркировочных ярлыков, весовые контроллеры, сканеры штрихкодов).
5. Локальная вычислительная сеть (ЛВС) и промышленная беспроводная сеть Wi-Fi.

### 5. Топология локальной и беспроводной сети склада

Для обеспечения устойчивого функционирования ТСД без обрывов сессий при перемещении между стеллажами проектируется бесшовная сеть промышленного Wi-Fi:

```
                  ┌───────────────────────────────────────────────┐
                  │    Оптический магистральный кабель (10 GbE)   │
                  │        из серверной заводоуправления          │
                  └───────────────────────┬───────────────────────┘
                                          │
                                          ▼
                  ┌───────────────────────────────────────────────┐
                  │     Коммутатор уровня агрегации/доступа       │
                  │   Eltex MES2428P (24x 1GbE PoE+ 802.3at,     │
                  │       4x 10GbE SFP+, бюджет PoE 370W)        │
                  └───────┬───────────────────────────────┬───────┘
                          │                               │
        ┌─────────────────┴───────────────┐               │ Медная витая пара Cat.6a
        │ Кабели UTP Cat.6a с PoE         │               │ к стационарным АРМ
        ▼                                 ▼               ▼
┌─────────────────┐               ┌─────────────────┐   ┌─────────────────┐
│ Точка доступа 1 │               │ Точка доступа 2 │   │ 4 стационарных  │
│ (Рампа, Зона Q) │               │ (Зона B, ряд 1) │   │ АРМ склада      │
└─────────────────┘               └─────────────────┘   └─────────────────┘
        │                                 │
        ▼                                 ▼
┌─────────────────┐               ┌─────────────────┐
│ Точка доступа 3 │               │ Точка доступа 4 │
│ (Зона B, ряд 6) │               │ (Зона C, взрыво-│
│                 │               │  защищённая)    │
└─────────────────┘               └─────────────────┘
```

#### Параметры радиопокрытия:
* **Точки доступа:** Промышленные двухдиапазонные точки доступа Wi-Fi 6 (Eltex WEP-3ax / Huawei AirEngine), поддержка стандартов 802.11k/v/r (Fast Roaming, время переключения между сотами $\le 30$ мс).
* **Размещение:** 4 точки доступа обеспечивают полное перекрытие зон A, B, C, Q и экспедиции с уровнем сигнала не ниже $-65 \text{ dBm}$ в самых удалённых межстеллажных проходах.
* **Зона C (ЛКМ/ГСМ):** монтаж точки доступа выполняется во взрывозащищённом термобоксе (маркировка 1Ex d IIC T6).

### 6. Требования к электроснабжению и климатическим условиям

1. **Категория надёжности электроснабжения:** II категория по ПУЭ (два независимых взаимно резервирующих источника питания с автоматическим включением резерва АВР).
2. **Заземление:** Контур защитного заземления с сопротивлением растеканию тока не более $4 \text{ Ом}$ (по ГОСТ 12.1.030-81).
3. **Климатический режим аппаратного шкафа КТС склада:**
   * Температура: $+18\dots+22\,^\circ\text{C}$;
   * Относительная влажность: $40\dots60\%$ (без конденсации);
   * Запылённость: не более $0.75 \text{ мг/м}^3$ (обеспечивается пылезащитными фильтрами шкафа со степенью защиты IP54).

### 7. Выводы по разделу

1. Комплекс технических средств полностью удовлетворяет требованиям ТЗ-01 по надёжности ($K_{\text{г}} \ge 0.998$), времени восстановления и производительности.
2. Промышленная беспроводная сеть с поддержкой стандартов 802.11k/v/r гарантирует непрерывность выполнения транзакций на ТСД без зависаний и потерь пакетов.
3. Проектные решения основаны на серийно выпускаемом оборудовании отечественного реестра ТОРП (Eltex) и доступных промышленных компонентах, что снимает риски санкционных ограничений.
