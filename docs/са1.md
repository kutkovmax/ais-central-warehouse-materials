## Документ СА-01. Модель взаимодействия с внешней средой и границы контура АИС

**Шифр документа:** АИС-ЦС-2026-СА-01

**Версия:** 1.0

### 1. Назначение документа

Настоящий документ определяет внешнее информационное окружение разрабатываемой АИС «Склад-МехПром», состав взаимодействующих внешних сущностей (подразделений завода, контрагентов, смежных систем), состав и формат входящих и исходящих информационных потоков, а также устанавливает строгие границы проектного контура.

---

### 2. Внешние сущности и окружение системы

Внешней средой для АИС центрального склада выступают подразделения АО «МехПром» и внешние контрагенты, не входящие в непосредственный штат складского комплекса, но инициирующие материальные и информационные потоки:

1. **Внешние поставщики ТМЦ:** источники поступления сырья, заготовок, покупных изделий, сопровождаемых товарно-сопроводительными документами и сертификатами.
2. **Отдел материально-технического снабжения (ОМТС):** источник плановых графиков поставок, спецификаций к договорам и нормативных лимитов цехов.
3. **Бюро входного контроля (ОТК):** субъект валидации качества, принимающий решения о годности партий к использованию в производстве.
4. **Цеха-потребители (МЦ-1, СЦ-2, ЦПО):** инициаторы материального расхода, формирующие производственную потребность в заготовках, деталях и расходных материалах.
5. **Бухгалтерия (Корпоративная учетная система / ERP):** внешний потребитель первичных данных для финансового баланса, расчета себестоимости и списания активов.
6. **Администратор ИТ-инфраструктуры (ОИТ):** служба обеспечения работоспособности СУБД, сети и политик резервного копирования.

### 3. Контекстная диаграмма взаимодействия (DFD Context / IDEF0 Context)

Информационные границы центрального склада и потоки данных формализуются следующей схемой взаимодействия:

```
                          ┌──────────────────────────┐
                          │   Нормативные лимиты     │
                          │   Графики поставок       │
                          ▼                          │
             ┌────────────────────────┐              │
             │      Отдел МТС         │              │
             └──────────┬─────────────┘              │
                        │ Спецификации               │
                        ▼                            │
  ┌──────────────┐  ТТН, УПД, Паспорта   ┌────────────────────────┐  Лимитно-заборные карты   ┌──────────────┐
  │  Поставщики  ├──────────────────────>│                        │<──────────────────────────┤     Цеха     │
  │     ТМЦ      │<──────────────────────┤   АИС ЦЕНТРАЛЬНОГО     │   Требования М-11         │ (МЦ-1, СЦ-2, │
  └──────────────┘    Акты ТОРГ-2        │        СКЛАДА          ├──────────────────────────>│    ЦПО)      │
                                         │  (АИС «Склад-МехПром») │  Накладные на отпуск      └──────────────┘
                                         └───────────┬────────────┘
                                                     │ ▲
                                 Акты приемки М-4    │ │ Задания на контроль
                                 Отчеты движения ТМЦ │ │ Решения о годности
                                                     ▼ │
                                         ┌───────────┴────────────┐
                                         │  Смежные заводские     │
                                         │  службы: Бухгалтерия,  │
                                         │  Бюро входного контроля│
                                         └────────────────────────┘
```

### 4. Спецификация информационных потоков через границу контура

#### 4.1. Входящие информационные потоки

| Идентификатор потока | Источник | Наименование потока данных | Состав ключевых атрибутов | Формат представления |
|---|---|---|---|---|
| **IF-IN-01** | Поставщик | Накладная поставщика (ТТН / УПД) | Номер ТТН, дата, поставщик, артикул, количество, масса, цена, номер транспортного средства | Электронный документ (XML/PDF) / Бумажный оригинал |
| **IF-IN-02** | Поставщик | Паспорт качества / Сертификат | Номер сертификата, завод-изготовитель, марка стали/сплава, номер плавки, дата выпуска, ГОСТ | Скан-копия PDF / Бумажный бланк |
| **IF-IN-03** | ОМТС | Договорная спецификация поставки | Код контрагента, плановый срок поставки, номенклатура, плановый объем | Запись в смежной БД / Реестр |
| **IF-IN-04** | Бюро ОТК | Заключение входного контроля | Номер акта ВК, номер партии, статус («Годен» / «Брак»), дата испытаний, ФИО контролера | Электронная виза в АИС / Акт СТП-08 |
| **IF-IN-05** | Цеха | Электронное требование на отпуск | Номер требования, цех-заявитель, номер заказа, код номенклатуры, требуемое количество | Экземпляр формы М-11 в АИС |
| **IF-IN-06** | Бухгалтерия | Справочник учетных цен ТМЦ | Код SKU, планово-расчетная цена за единицу, валюта, дата действия | Репликация справочника из 1С/ERP |

#### 4.2. Исходящие информационные потоки

| Идентификатор потока | Приемник | Наименование потока данных | Состав ключевых атрибутов | Регламент передачи |
|---|---|---|---|---|
| **IF-OUT-01** | Бюро ОТК | Задание на входной контроль партии | Внутренний номер партии, наименование SKU, объем выборки, номер зоны карантина (`Зона Q`) | Автоматически при проводке прихода |
| **IF-OUT-02** | ОМТС | Акт о расхождениях (ТОРГ-2 / М-7) | Номер акта, поставщик, расхождение по массе/штукам, описание дефекта | По факту выявления брака/недостачи |
| **IF-OUT-03** | Цеха | Накладная на отпуск материалов | Номер М-11, цех, фактически выданное количество, номер партии, сертификат | В момент физической передачи ТМЦ |
| **IF-OUT-04** | Цеха | Уведомление о резерве / дефиците | Номер требования, статус резерва (полный / частичный / отказ), доступный остаток | Мгновенно при обработке требования |
| **IF-OUT-05** | Бухгалтерия | Реестр приходных ордеров (М-4) | Номер ордера, дата, поставщик, номенклатура, количество, материально ответственное лицо | Ежесуточная пакетная выгрузка |
| **IF-OUT-06** | Бухгалтерия | Сводная ведомость списания ТМЦ | Код цеха, шифр затрат (номер заказа), объем списания по партиям | Ежесуточная пакетная выгрузка |
| **IF-OUT-07** | Руководство | Отчет по неснижаемым остаткам | Перечень позиций с остатком ниже критического лимита, динамика расхода | По расписанию (еженедельно) / On-demand |

### 5. Точки интеграции и архитектурные границы

Для обеспечения модульности и защиты ядра складской системы проектируются следующие механизмы интеграционного взаимодействия:

1. **Интерфейс «Склад — ОТК»:** Внутренний контур АИС. Рабочее место инженера ОТК проектируется как модуль внутри самой АИС «Склад-МехПром» с разграничением прав на уровне ролевой модели (RBAC). Это исключает внешние интеграционные задержки при передаче статусов годности.
2. **Интерфейс «Склад — Бухгалтерия/ERP»:** Внешний асинхронный интерфейс обмена данными на базе REST API (JSON) и очередей сообщений. АИС передает готовые агрегированные документы движения (М-4, М-11, ИНВ-19) без прямого вмешательства бухгалтерии в оперативные остатки ячеек.
3. **Интерфейс «Склад — Цеха»:** Клиентский веб-кабинет мастера цеха внутри АИС для подачи заявок и онлайн-мониторинга статуса комплектования.

---

### 6. Заключение

Четкая фиксация информационных границ предотвращает разрастание рамок системы (Scope Creep) и позволяет локализовать все критические функции партионного и адресного учета внутри ядра АИС, обеспечивая чистоту интерфейсов со смежными цеховыми и управленческими подразделениями завода.
