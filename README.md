# АС центрального склада материалов — Python MVP

Python-реализация вертикального среза АИС по ТЗ: справочник материалов, зоны и адресные ячейки, приёмка в карантин, входной контроль ОТК, остатки, движения и FIFO/FEFO-резервирование требований М-11.

## Запуск

Требуются Python 3.11+ и PostgreSQL.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
$env:DATABASE_URL = "postgresql+psycopg://warehouse:warehouse@localhost:5432/warehouse"
uvicorn app.main:app --app-dir backend --reload
```

Документация API: `http://localhost:8000/docs`.

## React-интерфейс

Веб-интерфейс находится в папке `frontend/` и работает поверх REST API.

```powershell
cd frontend
npm install
npm run dev
```

Локальный адрес интерфейса: `http://127.0.0.1:5173/`.

При локальном запуске frontend обращается к API по адресу
`http://127.0.0.1:8765`. Его можно изменить переменной окружения
`VITE_API_ROOT`.

## Реализованный контур

1. Создание материалов, поставщиков, зон и ячеек.
2. Регистрация прихода и размещение партии в зоне `Q` со статусом `UNDER_CONTROL`.
3. Фиксация решения ОТК: `ACCEPTED` или `REJECTED_QUARANTINE`.
4. Чтение остатков с разделением физического, зарезервированного и доступного количества.
5. Создание требования цеха и FIFO/FEFO-резервирование только годных партий.

Схема базы данных пока создаётся при старте приложения. Перед промышленным релизом её нужно заменить на Alembic-миграции, добавить полноценную авторизацию, outbox интеграции с 1С:ERP, акты ТОРГ-2 и завершение процесса фактической выдачи.
