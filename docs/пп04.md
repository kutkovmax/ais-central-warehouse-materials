### 1. Общие параметры складского комплекса

Центральный склад материально-технического снабжения АО «МехПром» расположен в отдельном капитальном одноэтажном корпусе (Корпус № 7) с прямым железнодорожным тупиком и крытой авторампой для разгрузки длинномерного и малотоннажного автотранспорта.

* **Общая площадь складского комплекса:** $3\,600 \text{ м}^2$.
* **Полезная площадь хранения:** $2\,850 \text{ м}^2$.
* **Рабочая высота потолков:** $8{,}5 \text{ м}$.
* **Количество грузовых ворот / доков:** 3 автомобильные рампы (гидравлические аппарели) + 1 ж/д ворота с въездной зоной под мостовой кран.
* **Климатические условия:**
  * Основной зал (Зоны A, B, экспедиция): отапливаемый, температура $+16\dots+18\,^\circ\text{C}$, относительная влажность до $60\%$.
  * Изолированная зона ЛКМ/ГСМ (Зона C): категорированное взрывопожароопасное помещение (категория В-Iа), приточно-вытяжная вентиляция с 8-кратным воздухообменом, температура $+12\dots+20\,^\circ\text{C}$.

### 3. Топологическое зонирование центрального склада

Территория склада дискретно разделена на 6 специализированных функционально-технологических зон:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        РАМПА РАЗГРУЗКИ / ПОГРУЗКИ                      │
├────────────────────┬───────────────────────────────────────────────────┤
│                    │     ЗОНА ВХОДНОГО КОНТРОЛЯ И КАРАНТИНА (Q)        │
│                    ├───────────────────────────────────────────────────┤
│  ЗОНА A            │                                                   │
│  Тяжёлый прокат,   │     ЗОНА B                                        │
│  отливки, поковки, │     Стеллажное адресное хранение                  │
│  электродвигатели  │     (подшипники, уплотнения, метизы, датчики)     │
│  (напольное и      │                                                   │
│   консольное)      ├───────────────────────────────────────────────────┤
│                    │     ЗОНА C (Изолированная) - ЛКМ, масла, эмали    │
├────────────────────┴───────────────────────────────────────────────────┤
│               ЗОНА ЭКСПЕДИЦИИ И КОМПЛЕКТОВАНИЯ ЗАЯВОК (EXP)            │
└────────────────────────────────────────────────────────────────────────┘
```

#### 3.1. Зона A — Крупногабаритные ТМЦ и металлопрокат
* **Тип размещения:** Консольные стеллажи для сортового проката (длина прутка до 6 м) и маркированные напольные площадки для чугунных корпусов и крупных поковок.
* **Номенклатура:** Прокат ст. 20, 40Х, 12Х18Н10Т; отливки СЧ-20, ВЧ-50; электродвигатели ВАО/АИР.
* **Ёмкость хранения:** 120 консольных ячеек + 80 напольных паллетомест ($1200 \times 800 \text{ мм}$ и нестандарт).

#### 3.2. Зона B — Комплектующие изделия и метизы (Основная зона АИС)
* **Тип размещения:** Фронтальные стеллажи высотой 5 ярусов с делением на паллетные места и полочные ячейки с пластиковыми лотками.
* **Номенклатура:** Подшипники, торцевые уплотнения, муфты, датчики давления, высокопрочные болты, гайки, шайбы, пружины.
* **Ёмкость хранения:** 6 стеллажных проходов, 12 стеллажей по 18 секций, 5 ярусов = $1\,080$ паллетомест + $2\,400$ мелкоячеистых контейнеров.

#### 3.3. Зона C — Химическая продукция, ЛКМ и ГСМ
* **Тип размещения:** Поддоны с защитными металлическими поддонами-ловителями на случай утечек; взрывобезопасные закрытые шкафы.
* **Номенклатура:** Растворители, эпоксидные грунтовки, эмали, консервационные смазки, индустриальные масла.
* **Ёмкость хранения:** 90 паллетомест для бочек ($200 \text{ л}$) и 40 шкафных секций для мелкой фасовки.

#### 3.4. Вспомогательные технологические зоны:
* **Зона Q (Quarantine / Приёмка):** Зона выгрузки, проверки сопроводительных накладных и временного размещения партий до получения штампа ОТК «Годен». Отпуск из зоны Q в производство физически заблокирован регламентом.
* **Зона EXP (Экспедиция отпуска):** Столы комплектования, упаковка партий под требования-накладные цехов (МЦ-1, СЦ-2, ЦПО), зона ожидания заводского цехового транспорта.

### 4. Стандарт адресации мест хранения

Для внедрения в АИС утверждается сквозной унифицированный координатный код ячейки хранения следующего формата:

$$\text{[Зона]}-\text{[Ряд/Стеллаж]}-\text{[Секция]}-\text{[Ярус]}-\text{[Ячейка/Лоток]}$$

#### Правила формирования компонент адреса:
1. **Зона:** Буквенный идентификатор (`A`, `B`, `C`, `Q`, `EXP`).
2. **Ряд/Стеллаж:** Двузначный номер стеллажного ряда (от `01` до `12`).
3. **Секция:** Двузначный номер вертикальной секции стеллажа вдоль ряда (от `01` до `20`).
4. **Ярус:** Однозначный номер полки снизу вверх (от `1` до `5`).
5. **Ячейка/Лоток:** Двузначный номер подразбиения внутри яруса (от `01` до `08`).

*Пример адреса:* `B-04-12-3-02` — Зона B (комплектующие), 4-й стеллажный ряд, 12-я секция, 3-й ярус по высоте, 2-й лоток (хранение партии подшипников).

### 5. Выводы обследования складского хозяйства

1. Размещение материалов в настоящее время осуществляется по принципу «свободного визуального поиска кладовщиком»: точные адреса в документах не фиксируются, что приводит к критическим задержкам комплектования.
2. Внедряемая АИС должна блокировать физическую возможность приходования партий без указания точного координатного адреса.
3. Система должна поддерживать различные типы адресов: крупногабаритные напольные квадраты (Зона A), паллетоместа и мелкоштучные лотки (Зона B), специализированные хим-места с контролем предельного объёма (Зона C).
